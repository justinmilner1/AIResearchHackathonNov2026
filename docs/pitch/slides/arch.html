Remember

Fifteen seconds. Remember has two layers. The bottom layer is a bench that makes every forgetting experiment comparable, with one frozen model and data stream, techniques as plug-ins, one GPU per run on Modal, and a pre-registered analysis. The top layer is a research agent using the bench to study why the model forgets. It proposes a hypothesis with a prediction, code decides what may run and gives the verdict, and a skeptic step re-tests whatever held.
