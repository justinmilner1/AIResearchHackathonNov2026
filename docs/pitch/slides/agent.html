Phase 2: the research agent

How the research agent works.

Grounding: a second task sequence on Tinker (Qwen3-8B, LoRA) checks the bench on another model · src/clharness/agent/explore.py

Twenty seconds. The research agent runs a loop, unattended. Exa finds published sources. An OpenAI model proposes a hypothesis, with its prediction, and sometimes its own technique as code. A code gate decides what may run, with a static check, a tiny-model check and a short GPU probe. Exa checks whether the idea has already been tested. The runs go out on Modal. A fixed rule gives the verdict, and the skeptic, our critic, re-runs what held and tests the cheapest alternative explanation. Then the agent chooses its own next search and the loop repeats. Beside the loop: the frozen bench, past.dev as shared memory between agent instances, an evidence trail of every source, and, as grounding, a second task sequence on Tinker with a different model.
