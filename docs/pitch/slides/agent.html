Twenty-five seconds. The second layer is the research agent, studying why the model forgets. Each hypothesis states a prediction before any run. Automated code decides what is allowed to run and a fixed rule gives the verdict, so the model never grades itself. Across four instances it proposed 108 hypotheses, 14 were refused, and 208 runs tested the rest. Thirty-two tested configurations were techniques the agent wrote itself, each passing a syntax check, tiny-model check, and short GPU probe first. Its skeptic step re-runs every confirmed result at two more seeds and tests the cheapest alternative explanation: nine held, and two were overturned by its own checks.
