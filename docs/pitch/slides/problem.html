The problem

A model that keeps learning forgets what it knew.

Dozens of papers studying continual learning and publishing results, very little standardization in the field: 
Each is tested on a different model, a different data stream and a different budget, so their results cannot be compared, and some conflict.

Different models

From 400 million parameters to 10 billion.

Different data

Each paper picks its own old and new domains.

Different budgets

Millions of tokens in one, billions in the next.

Remember

Twenty seconds. When a language model keeps training on new data, it forgets old knowledge. There are many published fixes, but each paper uses its own model, data, and compute, so we cannot tell which fix is best and some papers disagree.
