Phase 1: the bench

One frozen bench. Twenty minutes a run.

What we tested

Six published techniques: replay, learning-rate re-warming, LoRA, layer freezing, distillation, weight averaging. 

Several alone, and 14 in combination.

The run

Gemma 3 1B trains on code, then on legal text: 10 million tokens of each, the same stream every run.

Did it learn?

Perplexity on held-out text from the new domain, right after training on it, divided by the base model’s. Below 1 means it learned.

Did it forget?

Change in accuracy on four multiple-choice tasks, 500 questions each, against the model before training: ARC-Easy, HellaSwag, PIQA, PubMedQA.

Remember · the training harness and four baseline runs predate the event; everything else was built this weekend

Twenty-five seconds. We hold everything constant. One small model trains on code and then on legal text, using the same stream every run. A run takes about twenty minutes, so we can afford many. We track two scores: accuracy on four general multiple-choice tasks, two thousand questions in all, compared with the model before training; and perplexity on held-out text from the new domain right after training, relative to the base model. Six published techniques plug in as switches. We ran several alone and fourteen combinations, and we pre-registered what counts as a win. If asked, the questions are split into a selection half and a report half so we never pick and report on the same items. Legal is where learning shows, since the model already knew code-like text well, so its code perplexity did not improve. The training harness is prior work; the bench, techniques, analysis and agent are from this weekend.

Twenty seconds. The research agent runs a loop, unattended. Exa finds published sources. An OpenAI model proposes a hypothesis, with its prediction, and sometimes its own technique as code. A code gate decides what may run, with a static check, a tiny-model check and a short GPU probe. Exa checks whether the idea has already been tested. The runs go out on Modal. A fixed rule gives the verdict, and the skeptic, our critic, re-runs what held and tests the cheapest alternative explanation. Then the agent chooses its own next search and the loop repeats. Under the loop: the frozen bench, a second task sequence on Tinker with a different model as grounding, an evidence trail of every source, and past.dev as shared memory between agent instances.

Twenty-five seconds. The second layer is the research agent, studying why the model forgets. Each hypothesis states a prediction before any run. Automated code decides what is allowed to run and a fixed rule gives the verdict, so the model never grades itself. Across four instances it proposed 108 hypotheses, 14 were refused, and 208 runs tested the rest. Thirty-two tested configurations were techniques the agent wrote itself, each passing a syntax check, tiny-model check, and short GPU probe first. Its skeptic step re-runs every confirmed result at two more seeds and tests the cheapest alternative explanation: nine held, and two were overturned by its own checks.

Twenty-five seconds. First, we re-tested six published claims on the one bench, with the same model, data, and budget for each. Two reproduced: the standard recipe of replay plus learning-rate re-warming beats no fix, and peak learning rate is the main knob. Three failed to reproduce: replay alone, distilling on replay tokens, and freezing the top half instead of the bottom. LoRA reproduced in part, since it forgets less and learns less, but its rank claim held only after tuning its learning rate. A failed reproduction at our small scale is not proof the paper is wrong, and we say so.

Twenty-five seconds. Two findings came out of it. First, a lead that held at four seeds: with the same distillation and the same amount of legal learning, putting new knowledge in separate adapter weights lost 15 percent of the most fragile questions, against 69 percent on full weights. Second, an explanation that failed control checks. The agent first concluded damage was in the MLP blocks because a technique protecting them preserved fragile questions. But the skeptic step tested a simple control: plain slower training did better, losing 14 percent against 23 while learning more legal text. Protection came from adapting less rather than layer location. The agent caught its own mistake. Caveats if asked: the first lead is scoped to one learning rate; fragile questions are defined by full-weight runs, making full-weight arms look worse on them.

Twenty seconds. In summary, on this bench, tuning the learning rate matches or beats every published technique we tested, so any new fix should be judged against that. We have three leads to pursue with the same agent, each a hypothesis with a prediction the bench can test in twenty minutes: first, whether separate weights protect old knowledge over many domains; second, whether damage sits in particular layers when tested fairly; and third, since seeds lose the same questions and pick the same wrong answer, whether base model confidence can predict which before training.
